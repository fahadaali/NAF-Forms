# الاختبارات

`npm test` · `npm run check` (فحص الأنماط + الأنواع + الاختبارات معاً)

## لماذا `node:test` و`tsx`

بلا حزمة جديدة: `node --test` مدمج في Node 18+، و`tsx` كانت في تبعيات
التطوير أصلاً (للبذر). ستّ منصات وكثير من المحرّرين — فأقلّ ما يُضاف أفضل.

## ما يُختبر، ولماذا هذا بالذات

الدوال النقيّة في المسارات الأمنية التي غُيِّرت في معالجة
`audit/code-audit-2026-08.md`. وليست كل الشيفرة: ما يلمس D1 أو ربط Workers
لا يُختبر هنا، ويحتاج بيئة تشغيل — وهو عمل قائم بذاته.

| الملف | ما يحرسه |
|---|---|
| `validate-answer` | التحقق على الخادم: الخيارات من قائمتها، والمقاييس من مداها، والشبكة والترتيب والتاريخ والوقت والموقع |
| `upload-guard` | مرفق الإجابة من تخزيننا وحده — وإلا عرضت اللوحة رابطاً خارجياً بهيئة «السيرة الذاتية» |
| `url-guard` | وجهة الـwebhook: `https` وحده، ولا عناوين محجوزة ولا بيانات مثيل |
| `compare` | المقارنة الثابتة الزمن لكلمة مرور النموذج ورمز الواجهة |
| `public-form` | ما يصل المتصفّح: بلا أسرار، وبلا إجابات صحيحة، والمحميّ بلا أسئلة |
| `grade-answer` | تصحيح الاختبار، والمنطق الشرطي ووراثة القسم |
| `naf-format` | التاريخ والوقت بتوقيت الرياض مهما كانت منطقة المضيف |

## `TZ` معادية عمداً

سكربت `test` يضبط `TZ=America/New_York`. هذا مقصود: لو عاد التنسيق يقرأ
منطقة البيئة سقطت اختبارات التوقيت في أول تشغيل بدل أن يمرّ الخلل إلى
الإنتاج ويُقرأ ردّ مساءٍ على أنه ردّ ظهر.

وشُغِّلت كذلك تحت `UTC` (بيئة Workers) و`Asia/Tokyo` — نتيجة واحدة.

## هذه الاختبارات تعضّ

لا قيمة لاختبار لا يفشل. فأُعيد كل خلل أُصلح، وسُجّل ما سقط:

| الخلل المُعاد | اختبارات سقطت |
|---|---|
| التحقق لا يقيّد الخيارات بقائمتها | 5 |
| التوقيت يقرأ منطقة البيئة | 4 |
| حارس الوجهة يقبل العناوين المحجوزة | 1 |
| النموذج المحميّ يرسل أسئلته | 1 |

يُعاد هذا الفحص عند أي توسعة: اكسر ما تحرسه، وتأكّد أن شيئاً سقط.
