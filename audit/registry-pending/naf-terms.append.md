## ١٠. مصطلحات النماذج والاستبيانات

## ملحق §٥ — عزل الاتجاه في النصوص الصِرفة

القاعدة الحالية تُلزم بعرض كل رقم وتاريخ داخل عنصر عزل اتجاهي. في JSX يُستخدم
`<bdi>`، لكن **بعض النصوص تُبنى كسلاسل** (رسائل الخطأ، والقيم المُمرَّرة كـprop)
فلا تقبل عنصرًا.

المقترح إضافته إلى `naf-format`:

```ts
/**
 * عزل ثنائي الاتجاه لقيمة داخل نص عربي — مكافئ <bdi> في النصوص الصِرفة.
 * يستخدم محرفَي العزل من Unicode نفسهما اللذين يستخدمهما <bdi> داخليًا:
 * FSI (U+2068) و PDI (U+2069). غير مرئيين، ولا يظهران في النسخ ولا التصدير.
 */
export function bidi(value: string | number): string {
  return `⁨${value}⁩`
}
```

مطبَّق في `naf-forms` (`src/lib/utils.ts`) في ١٢ موضعًا، وينتظر التسجيل.

### التهيئة المسبقة والصلاحيات

شاشة `/users` كانت تسمّي ما لا وجود له بعد الدخول الموحّد: «إضافة مستخدم»
و«كلمة المرور الافتراضية 1234» و«إعادة تعيين» و«لم يغيّر كلمة المرور» —
أربع عبارات لا يقع منها فعل. ووظيفة الشاشة الحقيقية واحدة: تسجيل بريد
وصلاحية **قبل** أول دخول موحّد لصاحبه.

| المعنى | المعتمد | ممنوع |
|---|---|---|
| Pre-provisioning (شاشة) | تهيئة مسبقة | إدارة المستخدمين، الحسابات |
| تسجيل بريد قبل أول دخول | تسجيل بريد | إضافة مستخدم، إنشاء حساب |
| عضو سُجّل ولم يدخل بعد | بانتظار أول دخول | غير مفعّل، معلّق |

**و«محرّر» لا «عضو».** `mapLegacyRole` في `lib/sso.ts` تترجم الدور القديم
`member` إلى `editor` عند أول ربط، فقولُ «عضو» في شاشة التهيئة اسمٌ ثالث
لا مقابل له في شاشة الصلاحيات — والمسمّى الواحد للصلاحية الواحدة.

### رسائل الحدّ والرفض

| الحالة | النصّ |
|---|---|
| تجاوز حدّ المعدّل | محاولات كثيرة، حاول لاحقًا |
| نوع ملف مرفوض | نوع الملف غير مسموح |
| خيار خارج القائمة المعرَّفة | هذا الخيار غير متاح |
| قيمة خارج مدى المقياس | القيمة يجب أن تكون بين {min} و{max} |
| انتهاء وقت الاختبار على الخادم | انتهى وقت الاختبار |
| سؤال لا ينتمي إلى النموذج | هذا السؤال لا ينتمي إلى هذا النموذج |
| حذف يمنعه تعلّق ملكية | لا يمكن الحذف: لهذا الحساب مشاريع أو نماذج. انقل ملكيتها أولًا |
| وجهة تسليم خارجي مرفوضة | وجهة غير مسموح بها |
| لون خارج الصيغة المقبولة | لون غير صالح |
| قائمة خيارات مبتورة | قائمة الأسئلة غير مكتملة |

**«غير متاح» لا «غير صحيح» للخيار.** الخيار الذي أُزيل من النموذج بعد فتح
الصفحة ليس خطأً من المستفيد، و«غير صحيح» تحمّله ذنبًا ليس له.
