## أنواع حقول النماذج

قسم جديد. `naf-forms` أول منصة تحتاجه، وأي منصة تبني نماذج لاحقًا ستحتاجه.
الاختيار فيه قائم على **الشكل** لا على اسم المفهوم، لأن حقول النماذج تُعرض
بأيقونة صغيرة داخل شارة، فالتمييز البصري السريع هو الوظيفة.

| المعنى | الأيقونة | تُقلب في RTL؟ |
|---|---|---|
| نص قصير | `Type` | لا |
| فقرة | `Pilcrow` | لا |
| رقم | `Hash` | لا |
| رقم جوال | `Phone` | لا |
| بريد إلكتروني | `Mail` | لا |
| تاريخ | `Calendar` | لا |
| وقت | `Clock` | لا |
| اختيار من متعدد | `CircleDot` | لا |
| مربعات اختيار | `SquareCheck` | لا |
| قائمة منسدلة | `ChevronDown` | لا |
| مقياس خطي | `Ruler` | لا |
| شريط تمرير | `SlidersHorizontal` | لا |
| تقييم بالنجوم | `Star` | لا |
| تقييم شبكي | `Grid3x3` | لا |
| ترتيب / تفضيل | `ListOrdered` | لا |
| رفع ملف | `Paperclip` | لا |
| موقع على الخريطة | `MapPin` | لا |
| عنوان سكن | `MapPinHouse` | لا |
| اختيار بالصور | `Image` | لا |
| توقيع إلكتروني | `Signature` | لا |
| موافقة / إقرار | `ClipboardCheck` | لا |
| حقل مخفي | `EyeOff` | لا |
| عنوان قسم | `Heading` | لا |
| عنصر صورة | `Image` | لا |
| عنصر فيديو | `Film` | لا |
| فاصل بطاقة | `SeparatorHorizontal` | لا |

**ثلاثة تعارضات حُسمت لصالح المعنى، ويجب ألا تُعكس:**

- **مقياس خطي = `Ruler` لا `Scale`.** `Scale` مسجَّلة أعلاه بمعنى «جلسة قضائية».
  استخدامها لحقل نموذج يخلط كيانًا قضائيًا بعنصر واجهة.
- **عنوان سكن = `MapPinHouse` لا `House`.** `House` مسجَّلة بمعنى «الرئيسية».
- **موافقة = `ClipboardCheck` لا `BadgeCheck` ولا `CircleCheck`.** الأخيرتان
  دائرة بعلامة صح، و`CircleCheck` مسجَّلة لحالة «معتمد». الشكلان يلتبسان
  عندما يظهران في الشاشة نفسها — وهذا يحدث فعلًا في بنّاء النماذج.

## تصحيح لازم في «قواعد القلب» — غموض يجب حسمه

الجدول الحالي يسجّل: «رجوع → `ArrowRight` → تُقلب: **نعم**».

القراءة الحرفية (استورد `ArrowRight` ثم اقلبه في RTL) تُنتج سهم رجوع **يشير
يسارًا** في واجهة عربية، وهو خطأ ظاهر. فالجدول يسجّل — فيما يبدو — الصورة
الصحيحة في RTL سلفًا، و«نعم» تعني «هذه الأيقونة حسّاسة للاتجاه».

هذا الغموض سيتكرر في المنصات الأربع الباقية. **الاقتراح:** يُستبدل عمود
«تُقلب في RTL؟» بعمود **«اتجاه القلب»** بقيمتين صريحتين:

| المعنى | الأيقونة | اتجاه القلب |
|---|---|---|
| رجوع | `ArrowRight` | يُقلب في **LTR** (الاسم مسجَّل بصورته الصحيحة في RTL) |
| التالي | `ArrowLeft` | يُقلب في **LTR** |
| توسيع عنصر | `ChevronLeft` | يُقلب في **LTR** |
| تسجيل الخروج | `LogOut` | يُقلب في **RTL** (اسم Lucide باتجاهه الأصلي) |
| تراجع / إعادة | `Undo2` / `Redo2` | يُقلب في **RTL** |
| إرسال | `Send` | يُقلب في **RTL** |

**`ExternalLink` غير مذكورة في أي من قائمتَي القلب** — تحتاج سطرًا صريحًا.
`naf-forms` تركتها بلا قلب.
