# نظام استبانات ناف — NAF Forms

منصة موحّدة لبناء **الاختبارات**، و**التقديم الوظيفي (رفع السيرة الذاتية)**،
و**الاستبيانات والاستطلاعات** — مع أنواع بيانات متعددة، وقوالب جاهزة، ولوحة
ردود تفصيلية، وتصدير بأكثر من صيغة.

## المميزات

- **أنواع نماذج**: استبيان/استطلاع، اختبار (مع تصحيح تلقائي)، تقديم وظيفي.
- **١٦ نوع بيانات (حقول)**: نص قصير، فقرة، رقم جوال، بريد إلكتروني، رقم،
  تاريخ، اختيار من متعدد، مربعات اختيار، قائمة منسدلة، مقياس خطي، تقييم شبكي،
  تقييم بالنجوم (٥ نجوم)، موقع على الخريطة، عنوان سكن، رفع ملف، عناوين/فواصل.
- **الإلزامي والاختياري** مع تمييز الحقل الإلزامي بنجمة.
- **بنّاء نموذج** كامل مع إعداد مستقل لكل حقل، و**قوالب جاهزة** للاستخدام السريع.
- **تخصيص صفحة التقديم**: العنوان، المحتوى، الألوان، الصور، الشعار، مقاطع
  يوتيوب داخل الصفحة، الروابط، والملفات (مع التحكم بإمكانية التنزيل)، ورسالة
  ما بعد الإرسال.
- **صفحة تقديم على شكل بطاقات**: سؤال لكل بطاقة، انتقال سلس للتالي، وإمكانية
  الرجوع للسؤال السابق، وشريط تقدّم — بواجهة عربية RTL.
- **المشاريع**: لكل مشروع عدة نماذج/استبيانات بإعدادات مستقلة.
- **لوحة ردود تفصيلية** متكيّفة حسب نوع البيانات (رسوم بيانية للاختيارات
  والمقاييس، متوسطات، عرض المواقع والملفات)، مع تسجيل **تاريخ ووقت** كل رد.
- **تصدير الردود** بصيغتي CSV و JSON.
- **منطق شرطي**: إظهار/إخفاء الأسئلة بناءً على إجابات سابقة.
- **التحكم بالاستقبال**: حد أقصى لعدد الردود وتاريخ إغلاق تلقائي.
- **حماية بكلمة مرور** للنموذج، و**جمع بريد المستفيد**.
- **الدخول الموحّد**: المصادقة في مركز هوية ناف، وثلاث صلاحيات — مسؤول،
  محرّر، مستخدم (اطّلاع). صفحة التقديم تبقى عامة بلا حساب.
- **إشعار بريد** للمشرف عند وصول رد جديد (مزوّد HTTP على كلاودفلير، أو SMTP
  على مضيف Node).
- **مكافحة الإساءة**: منع تكرار التقديم بنفس البريد، مصيدة سبام، وتحديد معدّل.
- **التوزيع**: رمز QR وكود تضمين (Embed) لصفحة التقديم.
- **تكامل**: Webhook لكل رد + رسالة تأكيد تلقائية للمستفيد.
- **اختبارات متقدمة**: مؤقّت زمني، خلط الأسئلة، إظهار الإجابات، درجة نجاح.
- **تصدير Excel (.xlsx)** ورسوم دائرية وتصفية زمنية وطباعة رد فردي (PDF).
- **بنّاء أسرع**: سحب وإفلات لإعادة الترتيب، و٥ أنواع حقول جديدة (وقت، شريط
  تمرير، ترتيب/تفضيل، اختيار بالصور، توقيع إلكتروني).
- **وضع ليلي** للوحة التحكم.

## التقنيات

Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · Cloudflare D1 و R2 و KV
· Leaflet · `naf-auth` للدخول الموحّد

> **لا Prisma.** طبقة الاستعلامات في `src/lib/db.ts` تتحدّث إلى D1 مباشرةً
> على Workers، وإلى better-sqlite3 محليًا. أُزيلت Prisma ولم يبقَ منها إلا
> اسم مجلّد `prisma/` الذي يحمل ملف البذر.

## التشغيل محليًا

```bash
npm install
echo 'DATABASE_URL="file:./dev.db"' > .env   # يُنشأ المخطّط تلقائيًا عند أول تشغيل
npm run db:seed            # تحميل القوالب الجاهزة (اختياري)
npm run dev                # التطوير على http://localhost:3000
```

المخطّط يُنشأ تلقائيًا من `SCHEMA_SQL` في `src/lib/db.ts` عند أول اتصال —
لا خطوة هجرة محليًا.

> **الدخول محليًا** يحتاج ربط D1 وKV عبر miniflare (يتولّاه
> `initOpenNextCloudflareForDev` في `next.config.js`) ومتغيّرات المركز
> في `wrangler.toml`. وبلا ذلك يفشل كل طلب محميّ.

للإنتاج على كلاودفلير: [`DEPLOY.md`](./DEPLOY.md).

## إعدادات البيئة (.env)

| المتغير | الوصف | الافتراضي |
| --- | --- | --- |
| `DATABASE_URL` | مسار قاعدة SQLite (محليًا فقط) | `file:./dev.db` |
| `AUTH_CLIENT_SECRET` | **سرّ المبادلة مع المركز — بدونه لا دخول** | — |
| `PLATFORM_ID` | معرّف المنصة في المركز (مقارنة حرفية) | `NAF-Forms` |
| `AUTH_ISSUER` | أصل مركز الهوية، بلا شرطة أخيرة | `https://app.naflaw.sa` |
| `DEFAULT_ROLE` | صلاحية أول دخول لمن لا تهيئة مسبقة له | `viewer` |
| `NAF_TIMEZONE` | مرجع كل تاريخ ووقت في الواجهة والتصدير | `Asia/Riyadh` |
| `FIRST_ADMIN_EMAIL` | بريد أول مسؤول يُسجَّل بالزرع | `fahad2ao@gmail.com` |
| `R2_ACCOUNT_ID` / `R2_ACCESS_KEY_ID` / `R2_SECRET_ACCESS_KEY` / `R2_BUCKET` | تخزين الملفات عبر S3 (لمضيف غير كلاودفلير) | — (يحفظ محليًا) |
| `R2_PUBLIC_URL` | الرابط العام لحاوية R2 | — (تُقدَّم عبر الـ Worker) |
| `RESEND_API_KEY` + `MAIL_FROM` | إشعارات البريد على Workers | — |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` / `SMTP_FROM` | إشعارات البريد على مضيف Node | — |

> **الحسابات:** لا كلمات مرور في هذه المنصة. المصادقة كلها في مركز هوية
> ناف، والدخول من `{AUTH_ISSUER}/go/NAF-Forms` وحده (`/api/login` يردّ ٤١٠
> عمدًا). والصلاحيات ثلاث تُدار من «الفريق والصلاحيات»:
>
> | الصلاحية | ما تفعله |
> | --- | --- |
> | **مسؤول** | كل شيء + إدارة الفريق والصلاحيات |
> | **محرّر** | ينشئ النماذج ويحرّرها ويرى ردودها |
> | **مستخدم (اطّلاع)** | يقرأ ولا يكتب — الوسيط يردّ كل كتابة بـ٤٠٣ |
>
> ومن يدخل أول مرة بلا تهيئة مسبقة يأخذ `DEFAULT_ROLE`. وشاشة **«تهيئة
> مسبقة»** تسجّل بريدًا وصلاحية قبل أول دخول لصاحبه.
>
> صفحة التقديم `/f/[slug]` عامة، وكذلك `/api/f/*` و`/api/upload`
> و`/uploads/*` و`/certificate/*` و`/api/v1/*` (بحراسة رمز النموذج).
> وما عداها محميّ.
>
> **النشر على Cloudflare (D1 + R2 + KV):** راجع [`DEPLOY.md`](./DEPLOY.md).

## بنية المشروع

```
cloudflare/d1/*.sql         هجرات قاعدة البيانات (0001…0010) — تُطبَّق كلها
prisma/seed.ts              بذر القوالب لقاعدة التطوير المحلية (لا Prisma)
src/middleware.ts           حارس الدخول الموحّد + حارس «القارئ يقرأ ولا يكتب»
src/lib/sso.ts              إعداد naf-auth والمسارات العامة
src/lib/db.ts               طبقة الاستعلامات: D1 على Workers، sqlite محليًا
src/lib/repo.ts             الوصول إلى البيانات فوق تلك الطبقة
src/lib/public-form.ts      بناء نسخة النموذج المرسَلة للمتصفّح (بلا أسرار)
src/lib/field-types.ts      سجل أنواع الأسئلة (الحقول) وحرّاس القيم
src/lib/types.ts            إعدادات التخصيص (FormSettings) و DTOs
src/lib/naf-format.ts       التاريخ والوقت والأرقام — مرجعها توقيت الرياض
src/components/             بنّاء النموذج · صفحة التقديم · لوحة الردود · إدخال الحقول
src/app/                    الصفحات ومسارات الـ API
  api/f/[slug]/             المسارات العامة: submit · draft · visit · quotas · verify
  api/forms/ · api/projects/ · api/responses/ · api/members/ · api/users/
  api/v1/                   واجهة قراءة الردود (رمز لكل نموذج)
  auth/                     callback · backchannel-logout
  f/[slug]/                 صفحة التقديم العامة (بطاقات)
  forms/[formId]/edit/      بنّاء النموذج والتخصيص
  forms/[formId]/responses/ لوحة الردود والتحليلات
  certificate/[responseId]/ شهادة الاختبار
  members/ · users/         الفريق والصلاحيات · تهيئة مسبقة
```

## المسارات الرئيسية

| المسار | الوصف |
| --- | --- |
| `/` | الرئيسية: المشاريع والقوالب الجاهزة |
| `/projects/[id]` | نماذج المشروع |
| `/forms/[id]/edit` | بنّاء النموذج والتخصيص والنشر |
| `/forms/[id]/responses` | لوحة الردود والتحليلات والتصدير |
| `/forms/[id]/responses/[rid]/print` | طباعة رد فردي |
| `/f/[slug]` | صفحة التقديم العامة (رابط المشاركة) — **عام** |
| `/certificate/[rid]` | شهادة الاختبار — **عام** بمعرّف الرد |
| `/members` | الفريق والصلاحيات — مسؤول فقط |
| `/users` | تهيئة مسبقة (تسجيل بريد وصلاحية) — مسؤول فقط |
| `/denied` | صفحة الرفض — **عام** |
